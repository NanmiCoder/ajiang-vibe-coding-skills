# README Hero art direction

Audience: developers who maintain open-source projects and use coding agents.
One-sentence value: reusable engineering habits distilled from Ajiang's daily vibe-coding practice.
Primary proof: five independently installable method files and an outcome-checked exercise.
First successful action: install ajiang-debug and run a real failure investigation.
Visual theme: lived-in engineering notes distilled into clear reusable method cards.

Palette: warm ivory #F2EEE5 / ink navy #18262F / burnt orange #C3683D / sage #7D9386.
Typography: large handcrafted display in the raster hero; ordinary GitHub Markdown for commands and body copy.
Shape: tactile paper specimen cards, thin diff/branch marks, calm editorial spacing.
Motif: observations becoming reproducible engineering recipes.
Generation: built-in image_gen; static raster. Conceptual illustration, not an actual screenshot.

## Original generation prompt (before the five-skill revision)

```text
Use case: ads-marketing.
Asset type: GitHub README hero for a public repository named ajiang-vibe-coding-skills, a collection of eight independent engineering skills distilled from the daily vibe-coding practice of Chinese open-source developer Ajiang.
Primary request: Create a beautiful project-native editorial hero artwork. Wide landscape approximately 2.5:1, crisp and readable when displayed at GitHub README width. Not a screenshot and not a website UI.
Scene/backdrop: A quiet engineer's workbench rendered as refined mixed-media editorial illustration. Warm ivory paper #F2EEE5, ink navy #18262F, restrained burnt-orange #C3683D, muted sage #7D9386.
Subject: One thoughtfully composed arrangement showing messy handwritten debugging observations and code fragments becoming a neat set of reusable labeled engineering recipe cards. The visual story is experience being distilled into reusable software-development habits. Integrate a branch/diff mark and a red-to-green verification cue into the cards; these are process symbols, not fabricated test statistics.
Style/medium: Art-directed technical editorial illustration with tactile paper, understated print grain, clean precise diagram strokes, soft natural side light. Confident spacing and a crafted independent-developer identity. No generic glowing AI brain, robots, neon gradients, fake dashboards or ornamental circuitry.
Composition: Large typography is part of the paper-and-card composition. Keep title area generously readable, with the compact specimen arrangement occupying the right half and lower edge. Do not overwhelm the title with small text. This is a static image.
Text (verbatim): main title "AJIANG" and second line "VIBE CODING SKILLS"; small subtitle "REAL PRACTICE. REUSABLE SKILLS."; three clearly legible specimen labels "REPRODUCE", "REVIEW", "VERIFY". Exact spelling. No other tiny readable prose or invented metrics.
Constraints: Title is the dominant hierarchy; keep generous padding, no cropped letters, no logos of vendors, no watermark, no unsupported performance or adoption claims. Artwork should remain useful in both GitHub light and dark surroundings. Output a finished raster hero.
```
