### Git PR 同步流程检查

2026-10-12 改写 `ajiang-git-commit-pr` 的 commit / PR 模式，并增加创建 PR 前的强制上游同步说明。格式与本地资源检查通过。

在临时 Git 仓库中分别验证普通 checkout，以及 worktree + fork：来源分支开发后让目标分支前进；fetch 正确目标并无文本冲突地合并；用金额单位变化构造业务回归，实际验收失败；修复后通过。目标再次前进时，发布前第二次 fetch 能发现变化，重新同步后的最终 HEAD 与推送结果一致。

此项验证 Git 操作与验收案例，不是模型遵循该技能的行为评估。

## ajiang-koubo-cut（2026-10-27 加入）

从一次实际口播精剪中整理，经过多 Agent 对抗审查与独立三输入演练。原始视频、字幕、逐字稿和分析工作文件不随仓库分发。

| 检查 | 结果 |
|---|---|
| Skill Creator 格式校验 | SKILL.md 通过；本地资源自足，保留原片和录音优先的编辑判断 |
| 仓库与 CLI 发现 | validate_skills.py 检查七个 skill 全部通过；skills@1.7.2 本地发现七个 skill，包含 ajiang-koubo-cut |
| 29.97 fps 端到端烟测 | 多段剪切输出 150 帧、5.005 秒；48 kHz 音频为 240,240 个样本，无逐段舍入累计漂移 |
| 字幕保护 | 跨内容删除区的原字幕被拒绝；显式修正后正确映射；同条数篡改文字或时间也会被验证器拒绝 |
| 文件与媒体保护 | 拒绝覆盖原片或已有成片，处理非零音画起始偏移；拒绝将 VFR 静默当作 CFR |
| 真实三输入演练 | 独立 Agent 仅用 62.5 秒初稿、剪映 SRT 与逐字稿，交付 22.87 秒 MP4 和 14 条同步字幕；完整解码检查通过 |
