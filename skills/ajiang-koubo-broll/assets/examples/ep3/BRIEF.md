# ModelDial 第 3 期 B-roll v3 · 美术与制作总纲（所有章节 agent 必读）

## 0. 这是什么、为什么重做

- 一支约 6 分钟的口播视频（阿江，ModelDial「模型检测」功能上线）。我们做的是**整屏 16:9 的画面层**，用户把它盖在口播视频上，自己在右上角叠一个小圆头像、底部叠字幕。共 9 段（章节），每段单独出一个 MP4，按顺序首尾相接。
- 用户原始需求（原话）：「用 ego browser 去截图，制作的视频需要像 Screen Studio 一样正常的过渡放大缩小，关键的信息制作 MG 动画……核心思想就是能去截图，能看到真实网页的一些效果，其他部分你可以去生成，总之要把这个事情表达得很清楚。我想要这样的视频，直接剪出来就可以用。」
- 历史反馈（务必吃透）：
  - v1（浅色、截图推拉 + 平面 MG）：「截图放大那些都没问题，但是其他画面没有任何美感，不像 AE 风格」。
  - v2（深海军蓝舞台、镀铬字、粒子爆炸、印章、震屏）：用户「非常不满意」——过度包装、模板感、偏离“真实网页 + 讲清楚”。用户也明确讨厌“深蓝科技光效”。
  - v3 要求（原话）：「该有的动画效果、转场以及放大缩小都要很自然，不要过度包装，但该有的包装还是得有。」「最后合起来大家是同一个主题。」
- 所以 v3 = **真实网页是主角 + Screen Studio 式自然推拉 + 产品原生审美的精致 MG**。参考质感：Apple / Linear / Vercel / Screen Studio 的产品讲解片——克制、留白、每个画面只讲一件事，但每一帧都精致。

## 1. 视觉语言（全片统一，不许另造）

全部来自 modeldial.com 自己的设计系统（`src/lib/tokens.ts`）：

- **舞台**：`<Stage/>` 已由外壳统一画好（站点浅灰白 #F7F8FA + 柔光 + 极淡点阵）。**不要再画背景、不要暗场、不要整屏色块**。
- **颜色**：墨色字 `C.ink`；唯一强调色 = ModelDial 蓝 `C.blue`；`C.red` 只用于「掉包 / 不一致 / 被换掉的模型」；`C.amber` 只用于「相近」；`C.green` 只用于「一致 / 安全」。不加渐变字、不加发光、不加霓虹。
- **字体**：中文 PingFang SC，拉丁 Geist；模型 ID、URL、数字串用 `F.mono`（Geist Mono），写法照报告卡：`claude-opus-5-5`、`deepseek-v4.1-flash-1017`。
- **字号底线（1920×1080 设计坐标）**：标题 64–96；正文/说明 ≥ 30；辅助小字（标签、注释）≥ 24；截图里的小字算“纹理”不要求可读，但**你想让观众读的东西必须用镜头推近到 ≥ 24px 的有效字高**，或者在旁边用 MG 重写一遍大字。
- **表面**：白卡 `Card`（发丝边 + 带色相柔阴影），胶囊 `Chip`，结论胶囊 `Verdict`（一致/相近/不一致），模型胶囊 `ModelTag`（logo + 等宽型号），图标 `Icon`（lucide 线性风），品牌 logo `Logo`（lobehub，保留品牌色），字标 `Wordmark`。
- **禁用**（v2 的教训）：粒子爆炸、冲击波、印章砸入、震屏/手持抖动、故障闪、镀铬/金属字、体积光、深色舞台、3D 道具图片（`gen/*.webp` 不再使用）、满屏扫光、逐个元素发光。

## 2. 运动语言（同一个“嗓音”）

- **一切都在镜头里拍**：每个镜头内容包在 `<Cam moves=…>` 里。真实页面用它做 Screen Studio 推拉；**示意图/卡片画面也用它**——全程极慢漂移（比如 6 秒内 z 1.00→1.04），讲到哪个元素就推到哪（z 1.2–1.8），讲完拉回。推拉曲线统一 `E.cam`，单次推拉 0.9–1.3 s；不要连续不停地推，推到位后至少停 1 s 让人看清。
- **入场**：统一 `rise`/`At`/`Headline`（上浮 + 去模糊 + 淡入，0.5–0.6 s）；“落地”的小元素用 `Pop`（轻微过冲）。批量元素错峰入场要**越来越快**（非均匀错峰），收尾静止 ≥0.5 s。没有匀速直线运动。
- **转场**：用 `<Shot from to enter exit>`，只有 `fade / left / up / zoomIn / zoomOut / none` 六种，按两镜关系选（见 `src/lib/Shot.tsx` 注释）。**最自然的是 `none` + 镜头本身的推拉衔接**（例如推进页面里的某个元素 → 该元素被抠出来成为下一个示意图的主角）。一段之内转场种类别太杂，2–3 种足够。
- **节奏**：画面跟着口播走，用 `say('segN','词')` / `cue('segN','字幕原文')` 锚定，**不手写时间**。关键信息出现要比口播早 0.1–0.3 s 或同时；大约每 4–8 秒有一次画面推进（推拉、换焦点、新元素），但不要每句都换场景——宁慢勿快，关键信息落定后 hold ≥1 s。
- **光效**：最多给本段主角一次（例如结论出现时的一次单点 sheen），必须裁在圆角内；默认不用。
- **段首段尾**：每段第 0 秒开始 0.3–0.5 s 内内容入场（不要长时间空舞台）；最后 0.4 s 内容整体淡出到空舞台（`Shot` 的 exit 或自己做），这样 9 段首尾相接时，段与段之间是「内容离场 → 同一张舞台 → 内容入场」，衔接无痕。

## 5. 文案与事实

- 屏幕文字只写口播说过的结论，力度一致，宁短勿长；关键词与口播同词。不编数字。
- 页面真实数据可以照截图展示。访问量：口播说「快破 700 万」，首页显示 7,484,698——MG 里写「700 万+」，不要推近到首页那个精确数字。
- 两个开源项目：`lm-detector`（Ikaleio）与 `ModelTrace`（xqy2006）（用户稿件里写明）。
- Luna：口播「GPT-5 的 Luna / 6 的 Luna」，屏幕写 `GPT-5 · Luna`、`GPT-6 · Luna`（若 det-allmodels 截图里有对应型号，优先推近真实列表）。
- AA 对比数据（v2 已从两站截图核对过，用前自己再看一眼截图）：AA Intelligence Index 前四 Claude Opus 5.5 58 / GPT-6 Astra 57 / GPT-6.1 Sol 55 / Claude Fable 5.1 49（AA 榜首 Gemini 4 Carbon 无公开 API，未列入，要在画面注明）；ModelDial 首页：claude-opus-5-5 89.15 / gpt-6-astra 88.80 / claude-fable-5-1 87.25 / gpt-6.1-sol 86.60。
- 示意性的画面（比例、进度条、思考预算条）可以用，但要一眼看出是示意，不带假数字。

## 7. 工程规则

- 工程：`broll-v3/`（Remotion 4，React，TSX）。时间一律「段内秒」：`const t = useSec()`。
- **你只能改**：`src/segs/SegN.tsx`（你的章节），可新建 `src/segs/segN/` 放你的私有组件，可在 `public/segN/` 放你自己裁出来的图。**不许改** `src/lib/`、别的段、`entries`、`scripts`、`public/` 其它目录。lib 缺东西就在你的私有目录里写（可以复制 lib 组件改），并在报告里写明，我统一收编。
- `SegN.tsx` 默认导出组件 + 导出 `sfx: Sfx[]`（语义音效 `{t, k, v?}`，k 见 `src/lib/Seg.tsx` 注释；音效要稀疏、只给有辨识度的动作：点击、打字、卡片落位、结论出现、推拉转场。音源由总控统一做）。
- 纯函数、确定性：禁 `Math.random` / `Date`，伪随机用 `rand(seed)`。
- 类型检查：`npx tsc -p .`（只看你自己文件报的错）。
- **静帧自检（主要手段）**：`node scripts/still.mjs segN 0.5 3.2 7.8 … --tag=v1`（--scale 默认 0.5）→ `out/qa/segN/v1-sheet.jpg`，用 Read 看拼图。推近时文字清晰度要用 `--scale=1` 单独看几帧。每轮至少看：每个镜头的入场中、动作峰值、落定后。
- 预览视频（带口播，验证节奏）：`node scripts/preview.mjs segN --conc=2` → `out/preview/segN.mp4`。整段做完后至少渲一次，用 ffmpeg 抽帧对照 SRT 检查音画是否对上。别同时开多个预览渲染。
- 时间锚：`say('segN','词')` 拿口播说出某词的秒数（`src/data/timing.json` 里有每条字幕原文，先读它）；找不到会抛错。
- 样板：`src/segs/Sample.tsx`（`node scripts/still.mjs sample …` 可渲）展示了三种典型镜头的写法：真实页面推拉、示意图、选择+结论卡。照这个嗓音做，但要比它更精致、更饱满。

## 8. 各章节分镜方向（方向，不是死命令；口播全文在 timing.json，用户自己的画面提示在 `../script-final.md` 的【画面】）

**seg0 开场模拟掉包（42.6s）** 主角卡：`before-after-slider-scrub`（用于“肉眼看不出破绽”：拉杆扫过真 Opus / 掉包两份回答，两边几乎一样）。
节拍：①「花着顶配模型的钱 → 偷偷换成便宜模型」：一个模型胶囊/卡片的身份被悄悄替换（克制的遮罩换牌，不要爆炸）。②「本地测试环境 · 模拟偷梁换柱规则」：映射规则那一行（`Cutout` 只裁那一行）放进一个干净的卡片/窗口，镜头推近，`claude-opus-5-5 → deepseek-flash` 讲清楚。③ 请求链路示意（客户端 → 转发层 → 实际模型，参考样板但更精致）。④「CC 客户端调接口，返回的模型依然是 Claude Opus 5.5；问它是谁」：手搓一个 Claude Code 风格终端窗口（`Window chrome="app"`），打字提问、回答。⑤「后台塞一句系统提示词，一口咬定是满血 Opus」：系统提示词卡片插进转发层。⑥「肉眼看不出破绽」：主角卡。

**seg1 检测报告露馅（38.5s）** 主角卡：`scanline-annotate-focus`（浅色版：四角取景框依次咬合报告卡的关键区块并贴机器标签）。可选 `row-embed`（前三候选行落入）。
节拍：① 把掉包接口填进 ModelDial 模型检测页（真实页面 det-api → det-filled，光标点击「开始检测」）。② 不问身份，只让它写几百个随机数（右侧「本次检测」表盘/探针进度 + 数字流）。③ 报告卡出来（`user-report.jpg`），推近表盘「不一致」→ 推近「最接近 deepseek-v4.1-flash-1017」。④ 推近散点图：Opus 在 64 个里排第 37（可以把散点图 Cutout 抬出来放大标注），前三候选里没有 Opus。

**seg2 随机数指纹原理（45.0s）** 主角卡：`chip-grid-single-select-blackout`（三种问法里选中“写随机数”）、`pill-slot-cycle`（模型名称在槽里轮换，但下面的指纹分布不变）。
节拍：① 问「你是谁」、画鹈鹕骑自行车都能伪造，写随机数抓得准。② 路上拦个人报数字 → 7、42（例如 1–100 的数字点阵里 7 和 42 被点亮得特别多，克制的“热度”）。③ 两到三次固定探针：探针 1 写 218 个 1–355 的整数、探针 2 写 233 个（提示词卡打字 + 数字流）。可推近真实页面「检测是怎么做的」4 步。④ 名字和身份提示随便改（主角卡 pill-slot-cycle），偏爱的数字、几乎不碰的数字形成的分布（直方图）不变 →「靠提示词改不掉」。

**seg3 上线与使用方法（53.4s）** 主角卡：`bezier-source-converge-merge`（两个开源项目汇入 ModelDial）、`segmented-thumb-hero`（切到「复制提示词，手动检测」）。可选 `cursor-flyover`（首页导航“就在这个地方”）。
节拍：① 两个开源项目整合（GitHub 卡片汇合），「非常感谢他们的开源」。② 14 个模型系列、64 个型号：真实页面的 logo 行 + 「已收录的模型」弹窗；Claude/GPT/Gemini/Grok + 国产主力。③ 正式上线、就在这个地方、免费、打开就能测：首页导航「模型检测」→ 检测页。④ 操作：填 API 地址 + Key → 选待测型号 → 点开始（真实页面 Screen Studio 推拉 + 光标 + 打字）。⑤ ChatGPT 网页版 / Codex 怕降智到 GPT-5 · Luna / GPT-6 · Luna。⑥ 手动检测：切换（主角卡）→ 复制提示词 → 粘回 Codex/网页 → 把回答填回来对比。

**seg4 Key 安全（27.9s）** 主角卡：`element-body-moves`（contact-shadow-lift：Key 卡片离桌抬起）。
节拍：① 大家最关心 API Key 安全。② 只经过临时转发、去调那两次探针（真实页面的提示条「密钥经 ModelDial 临时转发……不写入数据库、缓存或日志」+ 右侧「密钥与请求经过哪里？你的浏览器 ↔ 临时转发 ↔ 目标 API」都是现成真素材，推近它们；再配 Key 走一遍链路的 MG）。③ 不写进数据库、缓存、日志（三个去处被拒，克制）。④ 一点开始检测，输入框立即清空（det-filled → 清空）。⑤ 建议：后台临时建一个 Key → 测半分钟 → 删掉（三步）。

**seg5 混掺与动态切流（44.9s）** 主角卡：`card-flip-reveal`（10 次请求卡逐张翻面：8 张真 Opus、2 张掺 Sonnet / 便宜模型）。可选 `timeline-travel`（不同时间段多测几次）。
节拍：① 第一层玩法回顾：改映射 + 改提示词 = 最粗暴（快速复现 seg0 的两个元素，小尺寸）。② 更隐蔽的：按比例混掺 / 动态切流（主角卡）。③ 上下文一长、Token 变贵 → 半路切到便宜模型（对话时间线 + 上下文长度增长 + 中途模型胶囊被换掉）。④ 别只测一次，不同时间段多测几次；突然变蠢时用手动模式把探针贴进对话（真实页面 det-manual）。
