## 2. 运动语言（同一个“嗓音”）

- **一切都在镜头里拍**：内容包在 `<Cam moves>` 里，真实页面和示意图一样。推拉曲线统一 `E.cam`，单次 0.9–1.3s，推到位停 ≥1s；讲到哪推到哪（z 1.2–1.8），讲完拉回；MG 画面全程极慢漂移（6s 内 z 1.00→1.04）。信息密集的画面保持正视，不倾斜。
- **入场**：`rise` / `At` / `Headline`（上浮 + 去模糊 + 淡入，0.5–0.6s）；落地小元素用 `Pop`。批量错峰越来越快，收尾静止 ≥0.5s。没有匀速直线运动。
- **转场**：`<Shot from to enter exit>` 只有 `none / fade / left / up / zoomIn / zoomOut`，按两镜关系选（`Shot.tsx` 注释），每段 2–3 种；优先 `none` + 镜头推拉衔接，或把页面元素抠出来当下一镜主角。透明度转场已是“先离场再进场”；私有组件里自己写叠化也必须这样，**不许两层字半透明叠在一起**。
- **节奏**：用 `say('segN','词')` / `cue('segN','字幕原文')` 锚时间，不手写秒数。关键信息比口播早 0.1–0.3s 或同时；每 4–8s 一次画面推进；纯文字标题卡 ≤3s，两张不连放。计数、翻牌在口播说完那个数时到位。
- **段首段尾**：第 0.3–0.5s 内容入场；最后一个 `Shot` 用 `exit='fade'`、`to ≈ 段长 + outDur/2 − 0.1`，**最后 2–4 帧必须是纯空舞台**（相邻段靠这个无缝衔接）。
