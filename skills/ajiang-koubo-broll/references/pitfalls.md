# 踩过的坑（动手前读一遍）

核对过第 3 期和第 4 期的对话记录（第 4 期的条目标“第 4 期”）。两种标注：

- **状态**：`实际` = 真的发生过；`预防` = 当时提前规避、没撞上（写明为什么还留着）。
- **证据**：`原话` = 第 3 期用户逐字原话；`早期原话` = 412 / 414 期，记在 video-mg-remotion 里；`审片` = 第 3 期独立审片 agent 在帧上确认过的；`制作` = 主控或子 agent 返工时的实测；`合稿实测` = 写这个 skill 时在沙箱里复现的；`shotcraft` = video-shotcraft 作者在别的项目里的判例（不是阿江本人的话，分开看）。
