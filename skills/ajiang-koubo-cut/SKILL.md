# 阿江口播精剪

把录制初稿剪成自然、连贯、信息完整的口播。默认直接完成一个主版本，交付同名 `.mp4` 和 `.srt`；保留原片。输入已明确时自主处理，不反复确认，不要求用户预先标记重录。

## 判断只守这几条

- **录音决定成片，稿子帮助理解。** 同一个意思选信息正确、完整、顺畅的一遍，不机械取最后一遍。完整且相关的即兴内容保留；不按稿子凑时长，不补录音里没有的句子或数字。
- **先选完整录次，再修气口。** 删除重录、未完成的起句、短重复和无信息等待，保持原有内容顺序。自然强调、不同含义的复述和短语气停顿不算重录。跨录次拼接只为去重或补全表达，不能改变原意。
- **SRT 和 ASR 是线索。** ASR 可能自动吞掉“你看三阶你看三阶”这类磕巴。重复起句、数字纠正、字幕冲突和段内接缝需要回到原音、波形或短片段对齐，保住字头与尾音。
- **字幕跟保留的录音走。** 修正专名和识别错误；跨删除区的字幕先拆分或重写成实际保留的文字，再映射时间。不能因只剩几十毫秒交集，仍把整条废稿字幕带回成片。

## 执行

读取 [执行接口](references/workflow.md)，使用本 skill 的两个脚本，避免每次重写剪辑程序。

1. 识别视频、剪映 SRT、逐字稿；粘贴的稿子保存到项目工作目录。检查音轨、帧率和字幕时间轴，抽查开头、中段、结尾的对应关系。使用原视频音轨；外部导出音频只有在已验证对齐时才替代。
2. 读完整 SRT 和稿子；字幕不准或重录多时，做一次独立原音转写并缓存。建立 `plan.json` 的保留段落和 `source.json` 的纠正后源时轴字幕。边界有疑点才追加局部复核，不反复转写全片。
3. `prepare` 建副本并编译一份共享时间线；按语速和噪声选择是否缩短长气口。阈值只是起点，不能据此证明无人声。先检查剪后音频/字幕/接缝，需要看节奏时再导出轻量预览；计划稳定后正式导出，内容修改后重渲。
4. `render` 保持原片分辨率与帧率。`verify --full-decode` 检查完整解码、帧数、音画时长及字幕合法性；抽查实际内容接缝和音画对应。发现问题修对应段，不重建整套流程。

默认保留原声与画面，不擅自加配乐、包装或烧录字幕。响度处理仅在音量影响观看时使用。完成后给出 MP4/SRT 链接、前后时长及必要限制。只做了转写/波形复核，就如实描述，不声称完整试听。
